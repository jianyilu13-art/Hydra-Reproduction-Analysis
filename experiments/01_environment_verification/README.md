# Experiment 1 – Environment Verification

## Objective

The objective of this experiment is to verify that the official Hydra pipeline can be successfully reproduced on the target hardware and software environment.

## Research Question

Can Hydra be successfully compiled and executed on the target system?

## Procedure

1. Prepare the software environment and install all required dependencies.
2. Build the Hydra workspace using the official source code.
3. Launch the Hydra pipeline with the official configuration.
4. Play the office RGB-D dataset.
5. Verify that Hydra successfully reconstructs the environment and generates the hierarchical 3D scene graph.

## Expected Outcome

- Successful compilation of the Hydra workspace.
- Successful launch of the Hydra pipeline.
- Successful playback of the office dataset.
- Successful visualization of the reconstructed mesh and hierarchical scene graph in RViz.

## Current Status

Completed.

The Hydra pipeline was successfully compiled and executed. The office dataset was processed correctly, and the hierarchical scene graph was visualized in RViz.
